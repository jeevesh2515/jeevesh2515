## ⚡ Featured work

### 🎮 [World War B: Bugfront](https://github.com/jeevesh2515/WWB) · [Play in browser](https://jeevesh2515.github.io/WWB/)
- Style-ranked 3D browser FPS: Three.js PBR rendering with Rapier physics compiled to WebAssembly.
- Eight waves, a boss, seven style ranks, and a Supabase Realtime 1v1 duel mode.

### 🎬 [Pressflick](https://github.com/jeevesh2515/pressflick) · [Try it](https://pressflick.vercel.app)
- Free text match-cut video generator: one word holds still while newspaper pages change around it.
- 1080p MP4 via WebCodecs, fully in the browser. No backend, account, watermark or tracking.

### 🎙️ [VoxFlow Voice Agent](https://github.com/jeevesh2515/voxflow-voice-agent-case-study) · [voxflow.cc](https://www.voxflow.cc/)
- Inbound voice agent for logistics desks on Amazon Connect, Lex V2, FastAPI and Groq.
- 22 identity-scoped tools, 2FA caller checks, HMAC-signed turns and 963 backend tests.

### 🛡️ [FinSentinel](https://github.com/jeevesh2515/finsentinel-case-study) · [Showcase](https://finsentinel-chi.vercel.app/)
- Local-first AML investigation assistant with Postgres row-level security and an append-only audit trail.
- Cut evidence-pack assembly from 1,070 ms to 44 ms p50, held by a CI benchmark gate. 771 tests.

### 🏥 [Clinical RAG Agent](https://github.com/jeevesh2515/clinical-rag-agent) · [Live demo](https://clinical-workflows.vercel.app)
- Hypertension-care assistant on LangGraph with hybrid retrieval (dense, BM25, Cohere rerank).
- Clinical maths runs in MCP calculator tools, never in the LLM. 55-question golden eval set.

### 🔍 [ExpertIQ Copilot](https://github.com/jeevesh2515/expertiq-copilot) · [Live demo](https://expertiq-copilot.vercel.app)
- Expert discovery: a six-node LangGraph RAG pipeline over ChromaDB and a knowledge graph.
- Next.js 16 UI with a 3D force-directed graph of co-authorship networks.
